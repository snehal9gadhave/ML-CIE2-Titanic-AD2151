# Machine Learning CIE 2 - Titanic Dataset

## Objective

To clean, analyse and prepare a Titanic dataset for future machine
learning tasks. Building a prediction model is not required.

## Dataset Information

-   **Dataset name:** Titanic Dataset
-   **File type:** CSV
-   **Original dataset shape:** 1301 rows and 10 columns
-   **Prepared dataset shape:** 1300 rows and 13 columns
-   **Dataset source:** Original Titanic CSV file used for this activity (The Titanic dataset.csv)

## Work Completed

1.  Dataset selection and understanding.
2.  Missing-value handling using median and mode.
3.  Duplicate record checking and removal.
4.  Exploratory Data Analysis using five visualisations.
5.  One-hot encoding of gender and embarked.
6.  Min-Max scaling of age, family and fare.
7.  Saving the prepared dataset as a separate CSV file.

## Final Results

-   Missing values in prepared dataset: 0
-   Duplicate rows in prepared dataset: 0
-   Min-Max scaling range for selected features: 0 to 1
-   Prepared dataset: `titanic_prepared.csv`

## Conclusion

The Titanic dataset was inspected, cleaned and prepared for future
machine learning tasks. Missing values were handled, duplicate records
were checked, and five visualisations were created. Categorical features
were encoded and selected numerical features were scaled. No prediction
model was built.
